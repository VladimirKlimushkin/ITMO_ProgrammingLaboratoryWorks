## Задание 1. Имена, ссылки и изменяемость

### Эксперимент A. Неизменяемый объект

```a = 10
b = a

print(a, b)
print(id(a), id(b))

a += 1

print(a, b)
print(id(a), id(b))
```

- **Файл** при компиляции выводит: 
`10 10
140703810184264 140703810184264
11 10
140703810184296 140703810184264`

 (После операции `a += 1` значение, связанное с именем b, не изменилось, потому что вместо изменения объекта python создает новый объект со значением 11).

### Эксперимент B. Изменяемый объект

```first = [10, 20]
second = first

print(first, second)
print(id(first), id(second))

second.append(30)

print(first, second)
print(id(first), id(second))
```

Дополним программу:
1. Переназначим second на новый список с теми же элементами.
```second = [10, 20, 30]
```

2. Сравним списки с помощью == и is.
```print(first == second)
print(first is second)
```

3. Изменим новый список и проверим, повлияло ли это на first.
```second.append(40)
print(first)
print(second)
```

4. Построим в REPORT.md две схемы связей между именами и объектами: до и после переназначения.
До переназначения - оба имени => один список. 
После - два имени => два разных списка.

 (После операции `a += 1` значение, связанное с именем b, не изменилось, потому что вместо изменения объекта python создает новый объект со значением 11).

### Вопросы для анализа (ответы)
Меняет ли `second = first` сам объект? 
Нет. Меняется только привязка имени second; объект остаётся тем же.

Почему операция над неизменяемым объектом приводит к связыванию имени с другим объектом?
Потому что неизменяемый объект нельзя изменить «на месте» - Python создаёт новый объект и перепривязывает имя.

Как определить, что два имени обозначают один объект?
Через a is b или id(a) == id(b).
